# Decisions

## 2026-11-08: OCI 시리즈 재구성

- 시리즈명은 「OCI Free Tier를 프록시, 리버스 프록시로 사용하기」로 통일한다.
- 프롤로그에서 포트포워딩·DDNS의 범위와 한계를 설명하고, 본편은 인바운드·선택적 아웃바운드·운영 확인으로 나눈다.
- 반복 비용 비교, 긴 설정 주석, 중복 목차는 줄이고 결정 이유·핵심 설정·확인 방법을 남긴다.
- 기존 slug와 `published: false`를 유지한다. 실측 결과와 정책상 보장은 구분하며, 원문에 근거가 없는 캐시 계층은 구성에서 제외한다.
